What does your PC cost in electricity?

PowerCost sits in the Windows system tray and estimates your PC's electricity cost, split by what it was doing (active, idle, sleep, off) and by tariff period (day and night), using the prices of your region.

What it does

Everything runs on your PC.

Costs by power state

Tracks active, idle, sleep and off time. While the PC is off the app cannot run, so it explains the gap afterwards from the Windows event log.

Real tariffs, as data

Day/night prices, weekends, holidays, seasons, VAT and clock changes come from editable tariff files. Bulgarian presets are included; add any country with a JSON file.

Dashboard and history

Today, week, month and year, with arrows to step back through earlier periods, a timeline, and "what if" scenarios such as shutting down at night.

Stopwatch

Press Start, play a game or render a video, press Stop, and see the energy and cost of exactly that time.

Budget alerts

Set a monthly budget and get ordinary Windows notifications when you pass 80 % or 100 % of it.

Light on resources

The tray tracker uses about 25 MB of memory and roughly 0.01 % of one CPU core. Closing the window keeps it tracking.

Honest numbers

PowerCost cannot read your wall socket. Every figure is an estimate and the app always shows how it was obtained.

MethodHowTypical error
CalibratedYou measure idle and full-load watts once with a plug-in wattmeter (10 minutes).about ±5 %
Measured sensorsCPU power from Windows counters and NVIDIA GPU power, plus a modelled rest of system.about ±15 %
Default modelEstimated from your hardware when no sensor is available.about ±30 %

Treat the cost as the right order of magnitude, not an audited bill. CPU readings depend on your hardware, GPU power is read for NVIDIA cards only, and tariff presets can be out of date: if your bill disagrees, believe your bill and correct the tariff. Read the full list of limitations.

Install

  1. Download PowerCost_0.1.0_x64-setup.exe and run it. It installs for your user only and needs no administrator rights.
  2. Follow the short setup wizard: region, tariff, laptop or desktop.
  3. Closing the window does not quit the app. It keeps tracking from the tray; use the tray icon's menu, Quit PowerCost, to stop it.

Windows may warn you

The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click More info, then Run anyway. You can check the download is intact:

  • SHA-256: 5d8fd897171b1d3baba6dba4fb63710595681392a9651437885197b179372f08
  • PowerShell: Get-FileHash .\PowerCost_0.1.0_x64-setup.exe

Requirements: Windows 10 or 11 (64-bit). The Microsoft Edge WebView2 runtime is built into Windows 11; on Windows 10 the installer fetches it if it is missing. Updating: download and run the newest installer; your data in %APPDATA%\PowerCost is kept. Uninstall: Windows Settings, Apps. There is no Linux or macOS version yet.

Private by design

Stays on your PC

All data lives in %APPDATA%\PowerCost. Nothing is uploaded: no account, no analytics, no crash reporting.

No network use

The only possible network call is an optional country lookup in the setup wizard, off by default. Tariff prices are never downloaded.

Open source

The full code and a plain-language privacy page are on GitHub, along with the reasoning behind each design choice.
